# BookNest — лабораторная работа 6A

Клиентская часть построена на React + TypeScript. Код разделён на `app/`, `pages/`, `features/`, `shared/` и `api/` внутри `src/`.

## Запуск

```sh
npm install
npm run dev
```

## Проверки

```sh
npm run build
npm run lint
```
