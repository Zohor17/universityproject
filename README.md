# BookNest — лабораторная работа 6

React + TypeScript SPA с маршрутизацией, изолированным слоем API, хуками запросов, Context темы/пользователя и формой на React Hook Form + Zod.

Для актуальной версии React Router потребуется Node.js 22.22 или новее.

## Запуск

```sh
npm install
npm run dev
```

## Проверки

```sh
npm run build
npm run lint
```
