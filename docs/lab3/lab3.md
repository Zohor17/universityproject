# Отчёт по лабораторной работе № 3

## Интерактивный каталог BookNest

**Студент:** Зорин Прохор Алексеевич

## Цель работы

Реализовать интерактивное клиентское приложение на чистом JavaScript, разделив данные, бизнес-логику и отображение.

## Выполненная работа

Каталог содержит 40 книг в `data/books.js` и пять жанров. Реализация разделена на модули:

- `data/books.js` — локальные данные каталога и жанры;
- `lib/books.js` — поиск, комбинированная фильтрация и сортировка без DOM и мутаций входных массивов;
- `ui/render.js` — единая функция `render(state)` и создание карточек/элементов списка через DOM API;
- `main.js` — один объект состояния, восстановление параметров, обработчики формы и делегирование кликов.

Поиск выполняется по названию и автору без учёта регистра. Фильтры жанра и доступности сочетаются с сортировкой по названию, году или рейтингу. Карточки позволяют добавлять книги в список желаемого и удалять их оттуда; счётчики обновляются вместе со списком. Кнопка сброса возвращает исходные фильтры. Фильтры и список желаемого сохраняются в `localStorage`; чтение и запись защищены обработкой исключений.

Данные карточек выводятся через `textContent`; обработчик кликов делегирован корневому элементу каталога. В `package.json` добавлены команды `npm test` и `npm run lint`, а `eslint.config.js` содержит конфигурацию ESLint.

## Проверка

Чистые функции проверены на тестовых наборах: поиск по автору и названию без учёта регистра, сочетание жанра и доступности, все три варианта сортировки и сохранение исходного порядка массива. Дополнительно проверено наличие 40 книг и пяти жанров. Все выполненные проверки прошли.

Команды ESLint и `npm test` не запускались: в доступной среде нет `node` и `npm`. Проверку работы интерфейса в браузере, восстановления данных после перезагрузки и пустого состояния нужно выполнить после запуска проекта через локальный сервер.

## Вывод

Каталог переведён на клиентскую архитектуру с локальными данными, чистыми функциями выборки, единым рендером, делегированием событий и сохранением пользовательских настроек. Итоговая проверка ESLint и браузерные сценарии остаются незавершёнными до запуска в среде с Node.js и браузером.
