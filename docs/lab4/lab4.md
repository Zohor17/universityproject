## Цель работы

Подключить клиентское приложение к публичному REST API и обработать загрузку, пустые результаты, ошибки и отмену устаревших запросов.

## Выполненная работа

Локальный каталог заменён поиском Open Library. Запросы вынесены в слой API:

- `api/client.js` содержит базовый URL, `URLSearchParams`, проверку `response.ok` и `ApiError` со статусом;
- `api/books.js` запрашивает страницы по 20 книг, нормализует ответ и получает сведения о произведении;
- `main.js` реализует debounce, отмену старого запроса через `AbortController`, пагинацию и состояния интерфейса;
- `book-detail.js` загружает карточку произведения по ID и показывает отдельную ошибку 404;
- `ui/render.js` выводит состояния, карточки и список желаемого через DOM API.

Список желаемого хранится в `localStorage` и не зависит от текущей страницы результатов. Ошибки сети, статусы 4xx и 5xx получают разные сообщения; у состояния ошибки есть кнопка повтора. Независимые запросы карточки и рейтинга выполняются через `Promise.all`.

Коллекция запросов Postman находится в `docs/lab4/api-collection.json`.

## Проверка

Статическая проверка подтверждает, что `fetch` используется только в `api/client.js`, URL-параметры собираются через `URLSearchParams`, проверяется `response.ok`, а запрос карточки использует `Promise.all`. Живые сценарии сети, Offline, отмены в панели Network и ответа 404 необходимо подтвердить в браузере перед сдачей; результаты не отмечаются как пройденные заранее.
