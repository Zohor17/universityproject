# Дерево компонентов BookNest

```text
StrictMode
└── App — состояние каталога, фильтров, выбранной книги и повтора запросов
    ├── SiteHeader — счётчик списка желаемого
    ├── FiltersPanel — controlled-поля; значения принадлежат App
    ├── Results section
    │   ├── Spinner | EmptyState | ErrorBox — состояние запроса
    │   ├── BookList — получает производный список
    │   │   └── BookCard — карточка одной книги
    │   │       ├── Badge — рейтинг и доступность
    │   │       └── Button — детали и список желаемого
    │   ├── Pagination — номер страницы принадлежит App
    │   └── BookDetailsPanel — получает состояние хука useBookDetails
    ├── WishlistPanel — данные принадлежат хуку useWishlist
    │   ├── EmptyState
    │   ├── Badge — количество книг
    │   └── Button — удаление книги
    └── Site footer
```

## Владельцы состояния

- `App`: строка поиска, жанр, сортировка, фильтр полного текста, страница, ключи повтора запроса и выбранный идентификатор книги. Фильтры здесь, потому что они управляют и запросом, и результатами.
- `useBooks`: состояние сетевого каталога (`loading`, `success`, `empty`, `error`), отмена запроса в очистке эффекта.
- `useBookDetails`: состояние отдельной карточки и отмена её запроса.
- `useWishlist`: список желаемого и восстановление/сохранение через `localStorage`.
- `filterAndSortBooks`: производный массив; исходный список не мутируется и вычисляется при рендере.

Презентационные компоненты получают данные и обработчики через props. Они не читают DOM и не владеют состоянием каталога.
