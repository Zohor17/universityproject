## Цель работы

Перенести каталог на React + Vite + TypeScript, разделить интерфейс на компоненты и типизировать данные.

## Выполненная работа

- Настроен Vite-проект с TypeScript в строгом режиме и `noUncheckedIndexedAccess`.
- Стили ЛР 2 подключены повторно.
- Реализованы отдельный слой API, отменяемые запросы каталога и деталей, поиск с задержкой, фильтрация, сортировка, пагинация и список желаемого в `localStorage`.
- Интерфейс разделён на переиспользуемые компоненты в `src/components/`; пропсы описаны интерфейсами, значения сортировки — union-типом.
- Схема дерева и владельцы состояния описаны в `docs/lab5/components.md`.

## Проверка

Исходники и конфигурация подготовлены для `npm run build` и `npm run lint`. В этой рабочей среде команды `node` и `npm` не доступны, поэтому сборка TypeScript/Vite и ESLint не запускались. Ошибки сборки и линтера не объявляются устранёнными без их запуска. Скриншот дерева React DevTools также пока не приложен.

## Вывод

Каталог перенесён на компонентную структуру React, состояние разделено между `App` и специализированными хуками, стили предыдущей лабораторной переиспользованы. Для завершения отчётной демонстрации необходимо запустить сборку и линтер в среде с Node.js и сохранить скриншот дерева компонентов.
