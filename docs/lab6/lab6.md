## Цель работы

Собрать многостраничное SPA с собственными хуками, изолированным API, глобальным контекстом, URL-фильтрами и формой с проверкой данных и серверных ошибок.

## Выполненная работа

- Часть A вынесла загрузку в `useFetch`, `useBooks`, `useBookDetails` и `useDebounce`; запросы отменяются при очистке эффекта. Добавлены `ThemeContext` и демонстрационный `AuthContext`. Подробный отчёт: `docs/lab6a/lab6a.md`.
- Часть B добавила маршруты `/books`, `/books/:bookId`, `/books/new`, `/books/:bookId/edit`, `/wishlist`, `/login` и `*`, общий layout с активной навигацией и `RequireAuth` для списка желаемого.
- Поиск, жанр, сортировка, фильтр полного текста и номер страницы записываются в query-параметры URL через `useSearchParams`.
- Одна форма используется для создания и редактирования. Схема Zod проверяет семь полей; межполевая проверка требует, чтобы год переиздания был не раньше первой публикации. Ошибки доступны через `aria-describedby`, `aria-invalid` и `role="alert"`; отправка блокируется на время сохранения.
- В проекте нет backend для CRUD. `src/api/editorBooks.ts` — локальная API-заглушка на `localStorage`: дубль названия возвращает 409, автор `Server Error 422` вызывает ошибку поля, `Server Error 500` — общую ошибку. Это демонстрационные ответы заглушки, а не ответы удалённого сервера.

Описание части B: [docs/lab6b/lab6b.md](../lab6b/lab6b.md).

## Проверка

Статически проверены наличие всех маршрутов, URL-параметров, схемы с межполевым правилом и расположение единственного `fetch` в API-слое. Сборка, ESLint и браузерные сценарии не подтверждены: команда `npm` в рабочей среде отсутствует, поэтому сборку/линтер и скриншоты маршрутов и ошибок выполнить здесь не удалось. Для текущей конфигурации проекта нужен Node.js 22.22 или новее.

Для ручного прогона после установки Node.js проверьте прямое открытие URL каталога с параметрами, обновление страницы деталей, редирект `/wishlist` на `/login`, межполевую ошибку, повтор названия (409), автора `Server Error 422` и автора `Server Error 500`. Сохраните скриншоты в `docs/lab6b/` после реального прогона.
