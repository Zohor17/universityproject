После установки Node.js запустите `npm run build` и `npm run lint`, пройдите сценарии из отчёта и сохраните фактические скриншоты в этой папке.

Для ответа 422 в форме автора введите `Server Error 422`. Для 409 сохраните книгу, затем создайте вторую с тем же названием. `Server Error 500` показывает общую ошибку формы. Эти ответы формирует локальная заглушка.
