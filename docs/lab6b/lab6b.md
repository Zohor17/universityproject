**Студент:** Зорин Прохор Алексеевич

## Выполненная работа

- Добавлены вложенные маршруты и общий layout с активными ссылками.
- Параметры поиска, жанр, сортировка, наличие полного текста и страница хранятся в URL.
- Детали книги загружаются по `bookId`; маршрут показывает отдельную страницу 404 при ответе API 404.
- Одна форма `BookFormPage` работает в режиме создания и редактирования и заполняется значениями локальной книги.
- Схема Zod хранит проверки семи полей и правило сравнения годов; React Hook Form связывает сообщения с полями.
- Список желаемого защищён `RequireAuth`; вход реализован демонстрационным Context без серверной аутентификации.
- CRUD реализован локальной API-заглушкой, поскольку backend задания не предоставлен. Заглушка моделирует 422, 409 и общую 500 ошибку; инструкция проверки находится в этом каталоге.

## Проверка

Статические проверки подтвердили определения маршрутов, привязку семи полей формы к `label`/ошибкам, наличие межполевого правила и единственный вызов `fetch` в `src/api/client.ts`. Компиляция, ESLint и браузерные сценарии пока не подтверждены: в рабочей среде отсутствует `npm`.

## Вывод

Реализованы маршруты, защищённая страница, сохранение состояния фильтров в URL и единая схема для создания/редактирования. Перед сдачей нужно установить Node.js 22.22+, запустить сборку и линтер и приложить реальные скриншоты сценариев.
